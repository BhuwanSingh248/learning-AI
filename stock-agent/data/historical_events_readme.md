# Historical Events Seed Dataset

This directory contains `historical_events.json`, which serves as a **seed dataset** for the Stock Agent.

## ⚠️ Important Disclaimer & Purpose

* **Purpose:** This dataset provides historical macro market events (e.g. trade wars, rate hikes, bank failures) to test the agent's semantic event similarity lookup and outcome analysis features.
* **Seed Status:** The asset return percentages (1d, 7d, 30d, 90d returns) mapped to each event are **mock/simulation outcomes** for demonstration purposes. They are **not absolute financial ground truth**.
* **Usage Constraint:** Do not utilize this data directly for live automated trading or quantitative investments without replacing it with verified historical price records from actual market feeds.
