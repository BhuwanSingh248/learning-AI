# Phase 3 - App Shell and Navigation Design

---

# Objective

Design the app shell and route structure before building screens.

---

# STEP 3.1.1 - Define app routes

Recommended routes:

* `/`
* `/results`
* `/stocks/:symbol`
* `/system`

---

# STEP 3.1.2 - Define shell layout

The app shell should include:

* top header
* page title area
* main content container
* global alert or status area

---

# STEP 3.1.3 - Define navigation behavior

Requirements:

* clear active route
* one-click path back to results
* route should preserve symbol context where useful

---

# STEP 3.1.4 - Define routing strategy

Use routes and search params so a user can revisit:

* selected symbols
* lookback days
* opened stock symbol

---

# Completion Checklist

* [ ] routes defined
* [ ] shell layout defined
* [ ] back navigation defined
* [ ] deep-link strategy planned
