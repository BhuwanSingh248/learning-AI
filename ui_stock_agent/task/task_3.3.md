# Phase 3 - Ranked Results Experience

---

# Objective

Design how multiple stock suggestions will be compared.

---

# STEP 3.3.1 - Define result layout

Choose one primary pattern:

* table on desktop, cards on mobile

This works best for score comparison.

---

# STEP 3.3.2 - Define required columns or fields

At minimum show:

* symbol
* score
* decision
* short reason

Recommended later:

* momentum
* sentiment
* event score

---

# STEP 3.3.3 - Define ranking behavior

Rules:

* sort by score descending by default
* highlight top result
* allow open detail action per row

---

# STEP 3.3.4 - Define result states

The results area should support:

* loading skeleton
* no results
* partial results
* full results

---

# Completion Checklist

* [ ] result layout chosen
* [ ] field list defined
* [ ] ranking behavior defined
* [ ] states documented
