# Phase 3 - Stock Detail and Explainability View

---

# Objective

Plan the detailed stock page or drawer that explains one recommendation.

---

# STEP 3.4.1 - Define detail sections

Minimum sections:

* symbol summary
* final decision
* score breakdown
* AI reason text

Recommended later:

* price chart
* news list
* corporate actions timeline

---

# STEP 3.4.2 - Define explainability rules

The detail view should:

* separate numbers from narrative
* show what influenced the outcome
* warn when data is missing

---

# STEP 3.4.3 - Define navigation behavior

The user should be able to:

* open detail from results
* return without losing the result list context
* share or bookmark the detail route

---

# Completion Checklist

* [ ] detail sections listed
* [ ] explainability rules written
* [ ] navigation behavior defined
* [ ] data gaps noted
