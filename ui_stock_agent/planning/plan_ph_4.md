# PHASE 4 - DESIGN SYSTEM & COMPONENT STRATEGY

---

## Objective

Define the visual system and reusable components needed across the UI.

---

## Design Principles

* clarity over decoration
* dense enough for analysis, not crowded
* decision states should be instantly scannable
* explanation sections should read calmly and clearly

---

## Core Tokens

* semantic colors for bullish, bearish, neutral, warning, error
* spacing scale
* radius scale
* typography hierarchy
* chart color palette

---

## Reusable Components

* app shell
* section header
* symbol input
* number/select field
* action button
* status badge
* metric card
* ranking table
* chart card
* empty state
* error panel
* loading skeleton

---

## Component Rules

* components should support loading and disabled states
* tables should collapse well on mobile
* badges should not rely on color alone
* cards should handle missing data gracefully

---

## Phase 4 Checklist

* [ ] design principles written
* [ ] semantic tokens identified
* [ ] reusable component list defined
* [ ] state variants noted
* [ ] responsive rules outlined
