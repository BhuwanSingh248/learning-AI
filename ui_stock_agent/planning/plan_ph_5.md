# PHASE 5 - DASHBOARD & RESULTS EXPERIENCE

---

## Objective

Plan the main UI surface where users run analysis and compare ranked outputs.

---

## Dashboard Sections

* hero or page intro
* multi-symbol analysis form
* request summary
* ranked suggestions area
* quick stats row
* notes or warnings section

---

## Analysis Form Requirements

* comma-separated or tokenized symbols input
* lookback days input
* clear validation messages
* example symbols for quick testing
* submit and reset actions

---

## Results Requirements

* sort by score descending by default
* show decision, score, and reason snippet
* surface top recommendation clearly
* allow open-in-detail action for each symbol

---

## Visual Indicators

* bullish / bearish / neutral badges
* score bars or progress indicators
* signal chips for momentum, sentiment, event impact

---

## Phase 5 Checklist

* [ ] dashboard layout planned
* [ ] form behavior defined
* [ ] result presentation defined
* [ ] ranking indicators planned
* [ ] top recommendation treatment decided
